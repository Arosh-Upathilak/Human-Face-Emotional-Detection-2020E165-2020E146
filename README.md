# Human Face Emotional Detection

## Description
This project implements a Human Face Emotional Detection system using OpenCV and deep learning. The model identifies human emotions based on facial expressions.

## Prerequisites
- Python 3.x
- OpenCV
- TensorFlow
- Necessary libraries listed in `requirements.txt`

## Installation and Setup

1. **Download Dataset**
   - Visit the Kaggle dataset link: [FER2013 Dataset](https://www.kaggle.com/datasets/msambare/fer2013).
   - Download the dataset as a ZIP file.
   - Extract the contents and rename the folder to `Datasets`.

2. **Install Dependencies**
   - Install the required libraries by running the following command:
     ```bash
     pip install -r requirements.txt
     ```

3. **Train the Model**
   - Execute the `Model.py` script to train the emotional detection model. The trained model will be saved as `emotion_detection_model.h5`.
     ```bash
     python Model.py
     ```

4. **Run the Main Application**
   - After training the model, run the `main.py` script to perform real-time emotion detection using your webcam or preloaded images.
     ```bash
     python main.py
     ```

## File Structure
- `Datasets/`: Contains the FER2013 dataset (downloaded and extracted from Kaggle).
- `Model.py`: Script to train the emotion detection model.
- `main.py`: Script to run the real-time emotion detection application.
- `requirements.txt`: List of required dependencies.
- `emotion_detection_model.h5`: Trained model file (generated by `Model.py`).

## Notes
- Ensure that your system has a functioning webcam for real-time detection.
- Modify the `main.py` script to specify image/video input for testing purposes if necessary.
